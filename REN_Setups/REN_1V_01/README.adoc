# REN_1V_01 setup

This folder contains the configuration files and deployment script of the REN_1V_01 Setup

## Setup description

This setup uses:

* 1 PLC 
* 1 DIO
* 1 VGR
* 1 Server 
** the factory scada 
** MQTT broker

Typical use: 

* send move commands to the VGR machine

## Deployment scripts

The `ansible` folder contains the playbooks used to deploy the setup on the Rennes platform



### Deploy instructions

```sh
cd REN_1V_01/ansible
ansible-playbook playbooks/push_plcs_code.yml
ansible-playbook playbooks/push_server_config.yml
```

Then
* login on the PLC and start rppmcontroller
* login on server and start mqqt and factory-scada (docker compose up)


## Configuration files

The `config` folder contains the setup specific configuration files

NOTE: some shared configuration files are located in `REN_shared` (ex: mqtt-broker, hosts.yml, ...)

# REN_1V_01 setup

This folder contains the configuration files and deployment script of the REN_1V_01 Setup

## Setup description

This setup uses:

* 1 PLC 
* 1 DIO
* 1 VGR
* 1 Server 
** the factory scada 
** MQTT broker

Typical use: 

* send move commands to the VGR machine

## Deployment scripts

The `ansible` folder contains the playbooks used to deploy the setup on the Rennes platform



### Deploy instructions


mosquitto
```sh
cd REN_shared/ansible
ansible-playbook playbooks/push_server_config.yml
```

```
ssh mbdo-admin@mbdo-server.local
cd ~/mbdo/mosquitto
sudo docker compose up -d
```

controllers and factoryscada
```sh
cd REN_1V_01/ansible
ansible-playbook playbooks/push_plcs_code.yml
ansible-playbook playbooks/push_server_config.yml
```

```
ssh pi@RevPi103156.local
cd ~/rppmcontroller_current_setup
~/rppmcontroller_current_setup
```

```
ssh mbdo-admin@mbdo-server.local
cd ~/mbdo/factoryscada
sudo docker compose up 
```

useful commands


see the factoryscada logs (useful if docker compse is launched  with `-d` option)
```
sudo docker logs scada-backend
```


## Configuration files

The `config` folder contains the setup specific configuration files

NOTE: some shared configuration files are located in `REN_shared` (ex: mqtt-broker, hosts.yml, ...)

# REN_1S1V_1C1V_1H1M_02 setup

include::docs/setup_description.adoc[]



## Deployment scripts

The `ansible` folder contains the playbooks used to deploy the setup on the Rennes platform



### Deploy and start instructions

#### deploy

mosquitto
```sh
cd REN_shared/ansible
ansible-playbook playbooks/push_server_config.yml
```

```
ssh mbdo-admin@mbdo-server.local
cd ~/mbdo/mosquitto
sudo docker compose up -d
```

controllers and factoryscada
```sh
cd REN_1S1V_1C1V_1H1M_02/ansible
ansible-playbook playbooks/push_plcs_config.yml
ansible-playbook playbooks/push_server_config.yml
```


TIP: using `ansible-playbook playbooks/push_plcs_config.yml -l RevPi03` will limit the action to a single PLC.

TIP: add `-i ../../REN_shared/ansible/inventories/proxyjump-hosts.yml` to run the ansible command when not directly connected to the mbdo network.

#### start factory scada on mbdo-server (ie. prod)

```sh
ssh mbdo-admin@mbdo-server.local

```

```sh
cd ~/mbdo/factoryscada
sudo docker compose pull
sudo docker compose up 
```

#### start factory scada locally (ie. dev) 

- start front end

```sh
cd ../../../cps-fischertechnik/factoryscada/frontend
```

```sh
npm run start
```

- start backend (using REN_1S1V_1C1V_1H1M_02 both mission and plc configurations files)

```sh
cd ../../../cps-fischertechnik/factoryscada/backend
```


```sh
./gradlew bootrun --args='--missions.parallelized.configuration.path=../../../dt-setups/REN_Setups/REN_1S1V_1C1V_1H1M_02/config/server/factoryscada/services/scada-backend/config/missions-parallelized-configuration.yml --configuration.path=../../../dt-setups/REN_Setups/REN_1S1V_1C1V_1H1M_02/config/server/factoryscada/services/scada-backend/config/configuration.yml --spring.profiles.active=prod --spring.config.additional-location=file:../../../dt-setups/REN_Setups/REN_1S1V_1C1V_1H1M_02/config/server/factoryscada/services/scada-backend/config/'
```

#### useful commands:

Connection allowing x display and ssh agent forwarding
```sh
ssh -X -A mbdo-admin@mbdo.inria.fr
export XAUTHORITY=$HOME/.Xauthority
```

see the factoryscada logs (useful if docker compse is launched  with `-d` option)
```sh
sudo docker logs scada-backend
```

see socket connection (in order to kill thread that haven't properly been closed)
```sh
netstat -tulnap
```

### Interaction with the platform

(requires to be connected to the same network, or run on the server)

- SCADA web page http://mbdo-server.local:9080
- Camera webpage http://mbdo-server.local:8080
- MQTT:  using MQTT Explorer : http://mbdo-server.local:1883

# Current State of the Turtlebot 3 Robots

Both Turtlebot 3 robots can be moved using the turtlebot3_teleop node as described in https://emanual.robotis.com/docs/en/platform/turtlebot3/basic_operation/#teleoperation.

The operation of the OpenMANIPULATOR with MoveIt in RViz as decribed in https://emanual.robotis.com/docs/en/platform/turtlebot3/manipulation/#operate-the-actual-openmanipulator is not reliable.

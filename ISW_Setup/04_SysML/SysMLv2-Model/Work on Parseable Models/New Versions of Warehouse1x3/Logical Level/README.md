# Small Warehouse SysMLv2 Model

This repository contains a **work-in-progress** SysMLv2 model that is parseable with the MontiCore Parser. It represents a Fischertechnik Highbay Warehouse with only three slots.

## Overview

The model represents the logical level of the warehouse system, focusing on its structure and behavior. It is designed to demonstrate the capabilities of SysMLv2 for modeling complex systems. Further details about the purpose of the model will be provided soon.

## Status

This project is currently under development.

## Overview

This directory contains all the relevant machine definitions of the Fischertechnik Factory.

### Machine Definitions

- **1x3Warehouse.sysml**  
    This file contains the initial description of the structure and behavior of the Warehouse with only 3 slots. *(Note: This may still contain some semantic errors.)*

- **ClawGripper.sysml**  
    This file contains the structural description of the Claw Gripper machine.

- **IndexedLine.sysml**  
    This file contains the structural description of the Indexed Line.

- **SortingLine.sysml**  
    This file contains the structural description of the Sorting Line.

- **VacuumGripper.sysml**  
    This file contains the structural description of the Vacuum Gripper.

- **Warehouse.sysml**  
    This file contains the initial description of the structure and behavior of the Warehouse. *(Note: This may still contain some semantic errors.)*

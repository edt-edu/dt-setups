## Fischertechnik 1x3 Highbay Warehouse SysMLv2 Model

This repository contains a **work-in-progress** SysMLv2 model. It represents a Fischertechnik Highbay Warehouse with only three slots.

## Overview

The model represents the logical level of the warehouse system, focusing on its structure and behavior. It is designed to demonstrate the capabilities of SysMLv2 for modeling complex systems. Further details about the purpose of the model will be provided soon.

## Status

The 1x3WarehouseV3 is currently under development.

## Fischertechnik ConveyorBelt SysMLv2 Model

This repository contains a SysMLv2 model which represents a Fischertechnik Conveyorbelt. 

## Overview

The model is a very close representation of the conveyor belt Python implementation, and is intended to be used for code generation, and therefore includes comments about problems with parsing it with the MontiCore SysMLv2 parser.

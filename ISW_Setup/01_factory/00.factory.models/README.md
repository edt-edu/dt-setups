# README

## Initial SysMLv2 Model
This directory describes the SysMLv2 model that represents the Fischertechnik Factory and the Elementary Machines. The focus of this model is primarily on the structure, particularly on how components can be abstracted.

## Project-Specific SysMLv2 Models
Additionally, there is a folder containing other SysMLv2 models that represent sub-machines. These models are often more detailed but are not tied to the specific structure of the "overall model."

Each corresponding folder includes additional README files with more specific information.
